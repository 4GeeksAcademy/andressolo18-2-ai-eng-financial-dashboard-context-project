# Mantener convención kebab-case para nombres de archivo

**Hecho**: Los archivos en `frontend/src/lib/` usan kebab-case (`financial-utils.ts`, `financial-types.ts`, `mock-data.ts`). Los componentes en `frontend/src/components/` también usan kebab-case (`kpi-card.tsx`, `income-outcome-chart.tsx`, `profit-percent-chart.tsx`, `dashboard-header.tsx`).

**Regla**: Todos los archivos de código del proyecto deben usar kebab-case. No mezclar PascalCase, camelCase ni snake_case en nombres de archivo.
